# 5. Matriz de Diseño Formal

La presente matriz documenta el conjunto de casos de prueba definidos para verificar el cumplimiento de los requisitos funcionales y no funcionales del Sistema Web de Gestión de Incidencias Georreferenciadas. Cada caso ha sido diseñado aplicando las técnicas descritas en el apartado anterior, permitiendo evaluar el comportamiento esperado del sistema de forma repetible y trazable.

De acuerdo con la planificación establecida para este entregable, los casos de prueba representan únicamente el diseño formal de las pruebas. En consecuencia, los campos correspondientes al resultado obtenido y al estado de ejecución permanecerán sin evaluar o con el valor **"No ejecutado"**, ya que su ejecución será realizada durante el Entregable 4.

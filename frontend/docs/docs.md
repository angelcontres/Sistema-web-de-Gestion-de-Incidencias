# Nombre de la actividad: Diseñar el prototipo de una interfaz web aplicando Bootstrap

El estudiante desarrollará una interfaz tipo dashboard que permita visualizar información organizada mediante tarjetas, tablas y elementos de navegación, aplicando el sistema de grillas y componentes de Bootstrap.

## Objetivo

Diseñar la estructura visual de una interfaz web mediante un prototipo, aplicando componentes de Bootstrap, organización de elementos y principios de diseño responsive.

## Instrucciones

El estudiante diseñará el prototipo de su proyecto web, representando las principales pantallas del sistema y su estructura visual, utilizando componentes de Bootstrap o herramientas de diseño equivalentes.

## Pantallas mínimas

- Inicio (dashboard o página principal)
- Gestión de datos (tabla)
- Formulario (registro o edición)

## Elementos obligatorios

- Navbar
- Cards
- Tabla
- Formulario
- Grid system (organización en filas y columnas)

## Navegación

- Debe existir conexión entre pantallas (menú o enlaces)
- No se requiere funcionalidad real (backend).
- Se evalúa la representación visual y estructural del sistema.

## Formato de entrega

HTML con Bootstrap

## Rúbrica

| Criterio                                     | Puntaje |
| -------------------------------------------- | ------- |
| Aplicación de Bootstrap (componentes y grid) | 20      |
| Organización visual de la interfaz           | 20      |
| Representación de pantallas                  | 20      |
| Diseño responsive (estructura adaptable)     | 20      |
| Coherencia con el proyecto                   | 10      |
| Presentación                                 | 10      |
